# MERN Blog Application

A colorful MERN Stack Blog Application built using React.js, Node.js, Express.js, and MongoDB.

---

# Features

- User Login
- Create Blog Posts
- Upload Images
- Delete Blog Posts
- Responsive UI
- Colorful Design

---

# Technologies Used

## Frontend
- React.js
- Vite
- JavaScript
- CSS

## Backend
- Node.js
- Express.js

## Database
- MongoDB

---

BLOG-APPLICATION

# Installation Steps

## Clone Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

---

## Install Frontend Dependencies

```bash
cd client
npm install
npm run dev
```

---

## Install Backend Dependencies

```bash
cd server
npm install
npm run dev
```
